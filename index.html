How to read the replay

Edmonds–Karp chooses a shortest residual path by breadth-first search. Ties follow edge input order. A forward arc uses unused capacity; a backward arc cancels existing flow on that same edge.

Each step displays the path just applied and the resulting flows. Optional cancellation arcs show the state after that step. The certificate and sensitivity table describe the completed optimum, even while replaying an earlier step.

Outage sets one edge’s capacity to zero. +1 gain increases only that edge by one and resolves the entire network. Being saturated does not imply an upgrade helps.

This is a bounded deterministic model, not a live traffic controller. It has no costs, travel times, lower bounds, or multiple commodities. Node positions are illustrative.
